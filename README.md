# Fênix

Fênix é um hub de mídia Android adaptável para TV, celulares e tablets. Este projeto é um **fork** do projeto original [ARVIO](https://github.com/arvio-tv/arvio), modificado para funcionar como uma interface (front-end) dedicada para o **fenixplayerbot**.

## Propósito do Projeto

Este aplicativo funciona como um front-end e reprodutor de vídeos hospedados no Telegram, otimizado para oferecer uma experiência fluida de consumo de mídia através da interação com o bot fenixplayerbot.

## Principais Funcionalidades

- **Interface Adaptável:** UI otimizada para Android TV, Fire TV, smartphones e tablets.
- **Integração com Bot:** Otimizado para funcionar como front-end para o **fenixplayerbot**.
- **Navegação de Mídia:** Busca e reprodução de conteúdos com metadados via TMDB.
- **Player Avançado:** Baseado em ExoPlayer/Media3 com suporte a troca de trilhas de áudio, legendas e ferramentas de IA.
- **Busca por Bot:** Busca os vídeos diretamente no bot **fenixplayerbot**.
- **Perfis Locais:** Suporte a múltiplos perfis com isolamento de histórico e progresso local.
